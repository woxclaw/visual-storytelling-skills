# Image Presets (14)

Adaptable image prompts. They are written in edit form; for a new image, drop the edit
opening and start from the scene description. When using Codex to edit a local image,
inspect it first and add explicit identity/content invariants.

Adapt subject, wardrobe, setting, and mood to the request. Keep only the capture cues
that are physically compatible with the requested scene.

## 1. Street vlog frame

Person vlogging on a busy street, phone in selfie mode, caught mid-sentence, imperfect framing, harsh daylight, slight motion blur.

```
Recreate this image while preserving the subject and scene: Person vlogging on a busy urban street, holding smartphone at arm's length in selfie mode. Mid-sentence expression with mouth slightly open, caught between words. Completely unposed casual posture, weight shifted to one side. Wearing everyday clothes - plain t-shirt. Hand gesturing while talking. Imperfect framing - head slightly off-center, cut off at awkward point. Deep phone-camera focus with pedestrians and cars softened by motion and distance, not DSLR bokeh. Harsh daylight, natural shadows on face. Slight motion blur on hair and gesturing hand. Autofocus a little soft. Looks like a paused frame from an amateur video. Smartphone front camera quality. Skin texture visible, no retouching. Wind-blown hair. Authentic street vlog aesthetic, minimally produced.
```
